# yaf NEWS

## 0.8.0

### Новое
- `yaf_api_get()` — универсальный get-запрос к любому сервису API Директа:
  батчинг, пагинация, повторы при временных ошибках, учёт баллов (атрибут `units`).
- `yaf_get_keywords()` — выгрузка ключевых фраз, с разделением фразы и минус-слов
  и ставками `Bid`/`ContextBid` (в валюте аккаунта) и `StrategyPriority`.
- `yaf_get_negative_keyword_sets()` — выгрузка наборов минус-фраз
  (всех или по `ids`).
- Отслеживание изменений через сервис `changes`:
  `yaf_check_campaign_changes()` — какие кампании изменились и где
  (параметры кампании, дочерние объекты, статистика);
  `yaf_check_changes()` — id изменившихся кампаний, групп и объявлений,
  с батчами по лимитам API и перепроверкой необработанных объектов;
  `yaf_changes_timestamp()` — текущее время сервера для первого запуска.
- У `yaf_get_campaigns()`, `yaf_get_adgroups()`, `yaf_get_ads()`,
  `yaf_get_bid_modifiers()` появились аргументы `fields`/`type_fields`
  для выбора полей и `raw = TRUE` для получения сырого ответа API.
- `yaf_get_campaigns()` теперь проходит все страницы результата и по умолчанию
  выгружает стратегию (`BiddingStrategy`) для кампаний всех типов (текстовые,
  ЕПК, мобильные приложения, медийные), минус-слова кампании
  (`NegativeKeywords`) и id привязанных наборов минус-фраз.
- `yaf_get_bid_modifiers()` поддерживает корректировки для планшетов,
  десктопов, по типу выдачи и уровню дохода.
- `yaf_get_ads()` возвращает колонку `display_url_path`.

### Изменения поведения
- Ошибки API больше не пропускаются молча: функции останавливаются с ошибкой
  класса `yaf_api_error`. Раньше упавший батч пропускался, и функция
  возвращала неполные данные без предупреждения.
- `yaf_get_campaigns()` при ошибке вызывает `stop()` вместо возврата `NULL`.
- Новый формат таблицы `yaf_get_campaigns()`: поля из блоков `TextCampaign`,
  `UnifiedCampaign` и т. д. идут без префикса типа
  (`BiddingStrategy.Search.BiddingStrategyType` вместо
  `UnifiedCampaign.BiddingStrategy.Search.BiddingStrategyType`), списки
  склеены в одну колонку через `; ` вместо `Items1`, `Items2`…, числовые поля
  остаются числами, а не строками.
- В `yaf_get_adgroups()` с дополнительными `fields` вложенные поля
  разворачиваются так же, а не в JSON-строку.
- В неинтерактивной сессии (Rscript, cron) при отсутствии токена
  функции сразу останавливаются с понятной ошибкой, а не ждут ввода.

### Исправления
- У всех функций пакета есть справка: параметры, возвращаемое значение,
  примеры.
- `yaf_get_bid_modifiers()` падала на видео- и смарт-корректировках
  (вызов несуществующей `safe_extract()`).

## 0.4.0

### Изменения в yaf_get_report()

- Добавлен аргумент `attribution` для выбора моделей атрибуции (FC, LC, LSC и др.).
- Аргумент `include_vat` теперь явно логический и маппится в IncludeVAT = "YES"/"NO" в API.
- Добавлен аргумент `save_dir` для кастомного пути сохранения отчётов (по умолчанию "reports").
- Добавлен аргумент `max_tries` для ограничения числа попыток опроса отчёта, чтобы избежать бесконечного ожидания.
- Удалён устаревший аргумент `atribution` (используйте `attribution`).
- Улучшена валидация аргументов (`login`, `date_range_type`, `include_vat`, `save_report`, `save_dir`, `max_tries`).
